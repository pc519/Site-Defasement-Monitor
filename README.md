# 🚨 Site Defacement & Uptime Monitor
A continuous website integrity monitoring tool built with Python using SHA-256 hashing to detect unauthorized content changes or downtime, sending instant alerts via Telegram Bot API.

# أداة مراقبة تشويه المواقع والتنبيه الفوري
أداة بايثون لمراقبة سلامة وتوفر المواقع الإلكترونية باستمرار عبر بصمة SHA-256، وإرسال تنبيهات فورية عبر تيليجرام عند توقف الموقع أو تغيير محتواه.
